# DashboardAdmin 
Admin Dashboard

Status: In Progress

A full-stack admin dashboard built with JavaScript, Node.js, Express.js, MySQL, and Vite.

Current Features:

- User management interface
- User registration form
- Client-side form validation
- REST API development
- MySQL database integration (in progress)

Currently Working On:

- Completing CRUD operations
- Connecting frontend components to backend APIs
- Improving validation and error handling

Technologies: JavaScript, Node.js, Express.js, MySQL, Vite, HTML, CSS
